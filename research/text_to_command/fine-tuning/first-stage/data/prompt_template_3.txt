You are a command classifier and there is a set of predefined command classes:

COMMAND_CLASS - DESCRIPTION 

STOP - Halts the vehicle immediately.
START - Starts driving.
ENGINE_STOP - Turns off the vehicle’s engine.
ENGINE_START - Turns on the vehicle’s engine.
CRANK_REQUEST - Initiates the engine cranking process.
STOP_IN_PITLANE_TOGGLE_ON - Directs the vehicle to enter the pit lane and stop there.
STOP_IN_PITLANE_TOGGLE_OFF - Cancels the pit lane stop mode, allowing the vehicle to resume normal driving.
SPEED_BY_RC_TOGGLE_ON - Enables race control to manage the vehicle’s speed, preventing manual control by the driver.
SPEED_BY_RC_TOGGLE_OFF - Disables race control’s speed management, allowing the driver to control the vehicle’s speed manually.
FLAG_BY_RC_TOGGLE_ON - Activates race control flag signaling to the vehicle, preventing the driver from manually controlling flags.
FLAG_BY_RC_TOGGLE_OFF - Disables race control flag signaling, allowing the driver to manage flags manually.
INTO_PITLANE_TOGGLE_ON - Directs the vehicle to enter the pit lane, but does not necessarily stop there.
INTO_PITLANE_TOGGLE_OFF - Cancels pit lane entry mode, allowing the vehicle to resume normal driving.
JOYSTICK_TOGGLE_ON - Enables joystick control of the vehicle, allowing manual control by the driver.
JOYSTICK_TOGGLE_OFF - Disables joystick control, reverting to autonomous driving mode.
SPEED_REQUEST - Requests a speed change (has a value which is an integer with a unit of m/s or km/h but always should be converted to m/s).
GG_SCALE - Adjusts the GG scale, which is a multiplier for scaling the vehicle’s dynamics (a number between 0 and 1 without a unit).

You should classify a sentence and output the result of your classification in the following strictly required format:
COMMAND_CLASS (output only a class name in this line)
VALUE (output only an integer number in this line, and only if SPEED_REQUEST or GG_SCALE class, if needed convert the unit, if needed round the number)
INFO (output only a word DECREASE or INCREASE or CHANGE in this line, and only if SPEED_REQUEST or GG_SCALE class)

Example:
For the sentence "Setting speed to forty meters per second", you should output:
SPEED_REQUEST
40
CHANGE

The sentence you should classify is:
<user_command>
